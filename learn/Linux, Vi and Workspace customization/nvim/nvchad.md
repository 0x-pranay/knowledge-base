Delete the current buffer : `:bd`



`:bd`

> Unload buffer [N] (default: current buffer) and delete it from the buffer list. 
>
> If buffer was changed it fails. Use [!]

`:bw`

> Like |:bdelete| but really delete the buffer.
>
> **bw => buffer wipeout not write**
